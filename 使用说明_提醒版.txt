兔兔桌宠 · 提醒版
==================

在原来的「36 套换装版」基础上，加了两件事：
  1. 一整套提醒系统：可以定时喊你（或喊别人）睡觉、起床、喝水、别久坐，
     到点兔兔会跳出来说话 + 响铃。
  2. 一整套动作：站着会自己伸懒腰、张望、转身，摸它头、喂它吃东西都有专门反应。


【怎么运行】
双击 兔兔桌宠_提醒版.exe 就行，不用装 Python、不用装任何东西。
第一次启动会慢几秒（它要把自己解压到临时目录），之后就快了。

如果 Windows 弹出蓝色的「Windows 已保护你的电脑」：
  点「更多信息」→「仍要运行」。
  这是因为 exe 没有买数字签名证书，不是病毒。

建议放在 D 盘或桌面任意文件夹；
不要放在 C:\Program Files 下面（那里没有写权限，设置和提醒就存不下来）。


【怎么设提醒】—— 三种入口，随便哪个
  · 右键兔兔 →「⏰ 提醒」→「提醒设置…」
  · 托盘小图标 →「⏰ 提醒设置…」
  · 右键 →「⏰ 提醒」→「马上提醒我…」（临时喊一句，不保存）

打开「提醒设置」后：

  1) 称呼
     填「宝贝」「小李」「妈妈」都行。提醒文字里写 {name}，
     到点会自动换成这个称呼。例：{name}，该睡觉啦 →
     「宝贝，该睡觉啦」。

  2) 快速添加（一键就有一条）
     🛏 睡觉 23:00   ☀ 起床 07:30   💧 喝水 每 60 分钟
     🧍 久坐 每 45 分钟   🍚 吃饭 12:00   👀 护眼 每 20 分钟
     🌙 晚安 22:30

  3) ＋自定义提醒
     自己写名称、时间、星期、它要说的话。

  4) 每条提醒右侧「改」可以编辑，「删」删除，
     左边小方框 = 开 / 关这一条。

两种提醒类型：
  · 每天定时 —— 例如 23:00。星期全不选 = 每天；
    只选一~五 = 只在工作日；也可以点「周末」。
  · 每隔一段时间 —— 例如每 60 分钟一次（喝水、久坐这类）。

到点的时候：
  兔兔会蹦一下 + 响铃 + 冒出气泡说那句话，气泡上有两个按钮：
  「知道啦」        关掉
  「5 分钟后再说」  过 5 分钟再提醒一次（分钟数可在编辑里改）


【几个顺手的开关】
  · 右键 → ⏰ 提醒 → 列表里点一条 = 直接开 / 关这条提醒
  · 右键 → ⏰ 提醒 →「🔕 静音 1 小时」：这段时间到点只记下来，不响不弹
  · 托盘图标 →「🔕 静音 / 取消静音」
  · 托盘图标 →「🐰 显示 / 隐藏」：把兔兔藏起来，提醒照样会出来


【提醒存哪里】
  提醒清单在 exe 旁边的 reminders.json；
  第一次运行会自动放好三条示范（睡觉 23:00、喝水每 60 分钟、久坐每 45 分钟，久坐默认关着）。


【它会自己动】（本版新增）
  站着发呆时，每隔十来秒会自己玩一个小动作：
    左右张望 · 歪歪头 · 甩甩身子 · 抖一抖 · 原地转身 · 点点头 · 蹦一下
    伸懒腰（会说「伸个懒腰～」）  ·  打哈欠（会说「哈啊～有点困了」）
  平时还一直有轻微的呼吸起伏，睡着时会变成更慢的呼吸 + 冒 z。

【互动动作】（碰它的时候）
  摸头            先缩一下，再舒服地左右晃，头上冒爱心
  连摸（冷却中）  甩甩身子，说「刚刚才摸过啦～」
  喂胡萝卜        一口一口地点头，嘴里冒胡萝卜和心心
  双击            跳得更高，还在空中转个身
  拎起来拖动      会随着手的速度往一边歪，松手掉下去「啪」地压扁再回弹
  提醒到点        弹起来 + 甩两下 + 冒一个感叹号
  专注完成        原地撒花转圈
  转圈撒花        心心、星星、音符一起飞

【想让它当场表演】
  右键 →「🎬 表演动作」，12 个动作随便点：
    蹦一下 / 开心蹦跳 / 原地转身 / 左右张望 / 歪歪头 / 甩甩身子 /
    抖一抖 / 伸懒腰 / 打个哈欠 / 点点头 / 转圈撒花 / 晕一下

  （小提示：素材是一张静态立绘，动作是用缩放、旋转、位移 + 粒子特效算出来的，
    所以 36 套衣服不用重画也能动。）


【和旧版的关系】（重要）
  · 新版和旧版共用同一个 pet_config.json：穿搭、亲密度、大小、置顶这些都接着用，
    打开就是你现在这身衣服，不用重新选。
  · 提醒单独存在 reminders.json，旧版看不到也不会覆盖它。
  · 两个 exe 不要同时开 —— 会变成两只兔子抢同一份配置。
    想回旧版：退出新版，双击 兔兔桌宠_换装版.exe 即可。


【原有玩法，一个都没少】
  左键拖动      把它拎起来，松手会掉下去弹一下
  单击          摸摸头（好感 +1，3 秒冷却）
  双击          蹦一下
  右键          全部功能：
                 · 换装衣橱（36 套完整造型 + 实时预览 + 随机一套）
                 · 摸摸头 / 喂根胡萝卜
                 · 🎬 表演动作（本版新增）
                 · 专注计时 15 / 25 / 45 分钟（番茄钟）
                 · ⏰ 提醒（本版新增）
                 · 跟着鼠标走
                 · 自由散步（手动：点一下才走，关掉就原地待着）
                   ※ 每次打开都是「不动」状态，不会自己溜达；
                     想让它散步就在菜单里点一次，这一次运行内一直走。
                 · 偶尔自言自语
                 · 窗口置顶 / 大小（小中大）
                 · 去睡觉 / 回到地面
                 · ⚙ 更多 → 开机自动启动 / 退出
                   （开机自启默认是关的，不会被偷偷加到启动项里；
                     想要开机就有它，才去这里手动勾上。）
                   （退出收在二级菜单里，是为了避免手一抖把兔兔点没了：
                     兔子站在屏幕最下面，菜单只能往上弹，鼠标紧挨着的就是最后一项。）

  真点「退出」时还会再弹一个小窗问一句「真的要让我回家了吗？」
  默认按钮是「再陪我会儿」，按 Esc 或直接回车都是它——手滑、或者键盘被别的程序
  顶了一下，都关不掉兔兔。只有明确点「👋 再见」才会真的退出。

  托盘右下角还有个小图标：显示隐藏、换装、摸头、提醒设置、快速专注、静音、退出。


【亲密度】
摸头 +1、喂食 +3、完成一次专注 +4、陪着你每分钟 +0.15。
共 5 级：刚认识 → 眼熟 → 朋友 → 好朋友 → 最好的朋友。


【文件说明】
  兔兔桌宠_提醒版.exe   主程序
  pet_config.json       穿搭 / 亲密度 / 设置（和旧版共用）
  reminders.json        提醒清单
  error.log             只有出错时才出现，可以删


【系统要求】
Windows 10 / 11，64 位。
